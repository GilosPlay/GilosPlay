# GilosPlay 👋

This repository contains the GilosPlay website, built with React and Vite.

## Development

Install dependencies with `npm install`, then start the development server with `npm run dev`.

## React + Vite

The app uses Vite for development and builds. Official React plugins include [@vitejs/plugin-react](https://github.com/vitejs/vite/tree/main/packages/plugin-react) and [@vitejs/plugin-react-swc](https://github.com/vitejs/vite/tree/main/packages/plugin-react-swc).

For more information about the React Compiler, see the [React documentation](https://react.dev/learn/react-compiler/installation). Oxlint's TypeScript configuration is described in the [Vite React TypeScript template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts).
